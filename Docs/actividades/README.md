# Registros de actividades (estándar)

Carpeta para **dejar constancia formal** de trabajos puntuales (descubrimiento BD, consultas operativas, épicas, documentación, etc.), con el mismo esquema que usa el equipo en informes de gestión.

## Estructura obligatoria de cada registro

1. **Descripción** — Qué se elaboró y por qué importa en el proyecto.
2. **Objetivo de la documentación** — A quién sirve (desarrollo, QA, operaciones) y qué ambigüedad elimina.
3. **Resumen de directrices definidas** — Viñetas con reglas, convenciones, consultas o decisiones tomadas.
4. **Resultado / impacto esperado** — Efecto en gobernanza, pruebas, despliegue u onboarding.
